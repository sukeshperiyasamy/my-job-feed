# 09 — Unified Web Dashboard

**URL:** `http://localhost:8000` (FastAPI Native Gateway)  
**Location:** `C:\sukesh\job\dashboard\index.html`  

---

## Features

1. **Overview:** Real-time metrics on discovered jobs, matched candidates, pending approvals, and submission counts.
2. **Job Explorer:** Browse listings, filter by status, trigger on-demand scraping and AI tailoring.
3. **Resume Library:** View master candidate profiles and inspect generated ATS PDFs.
4. **Approval Queue:** Review pending applications, inspect captured screenshots, and execute 1-click Approve or Skip actions.
5. **Repo Benchmark:** Live status of all underlying open-source modules and running processes.
6. **Settings:** View safety thresholds, whitelisted domains, and local AI connection endpoints.
