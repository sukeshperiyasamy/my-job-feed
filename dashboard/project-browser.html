Account setup checklist

1. Open a connection from the dashboard. Its website opens in this browser.

2. Create the account or sign in yourself. Choose “Remember me” if the website offers it.

3. Return to Connections and choose “I’m signed in.” This records your confirmation, without reading your password.

4. Keep this window open while working. The project can reopen the same profile later.

Account data stays in this project’s browser profile on this PC. This is separate from personal Chrome/Edge profiles. A saved login does not approve an application or enable unsupported automatic posting.
